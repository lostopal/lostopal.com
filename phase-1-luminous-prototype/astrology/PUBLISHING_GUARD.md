# Astrology publication guard

The complete Lost Opal Astrology learning hub in `index.html` is a private,
local workshop. It is intentionally available at the local `/astrology/` route
so its meanings, sources, and structure can be developed in context.

## Initial public release rule

When the Lost Opal prototype is first approved for publication:

1. Do **not** publish the full `index.html` Astrology workshop at `/astrology/`.
2. Serve `coming-soon.html` at the public `/astrology/` route instead.
3. Keep the workshop and its unfinished reference content private/local.
4. Before public release, change the Coming Soon page's robots directive from
   `noindex, nofollow` only if the owner wants the holding page indexed.
5. Replace the Coming Soon page with the complete learning hub only after the
   owner explicitly approves the Astrology content for publication.

This rule does not authorize publishing the rest of the site. Nothing should be
published until the owner separately asks for publication.
